# 雅思 / 托福词汇 · 默写练习

一个可切换《雅思词汇真经》和《托福词汇》的在线默写练习网站。

在线访问：[https://yibaofan1984.github.io/IELTS/](https://yibaofan1984.github.io/IELTS/)

## 功能

- 《雅思词汇真经》按书中的 22 个 Chapter 选择练习单元
- 《托福词汇》按书中的 48 个 List、Level 1–6 选择练习单元
- 托福词条保留原书顺序、中文释义、词性和英文例句
- 显示中文释义与英文发音提示
- 提示线数量严格对应答案中的英文字母数量
- 答错自动加入当前 Chapter 的错词本
- 可单独练习错词，答对后自动移出错词本
- 错词数据保存在浏览器本机，无需登录

## 本地运行

```bash
pnpm install
pnpm dev
```

## 构建

```bash
pnpm build
```

词汇内容按项目提供的两本 PDF 整理。
